## Codex workflow and token efficiency

- Prioritise coding, implementation, and verification over explanatory responses.
- Keep communication exceptionally concise.
- Never list modified files unless explicitly requested.
- Avoid detailed change summaries, code walkthroughs, and redundant commentary.
- When working on large tasks, split implementation into small, independently verifiable stages.
- Use `CODEX_HANDOFF.md` as the persistent record of progress, remaining work, decisions, and blockers.
- Update the handoff after each completed stage.
- Execute only the assigned stage unless explicitly instructed otherwise.
- Avoid reading unrelated files, repeating investigations, or redoing completed work.
- Prefer focused testing over unnecessary full-project verification, except when broader testing is required.
- Preserve existing architecture, conventions, and functionality.
